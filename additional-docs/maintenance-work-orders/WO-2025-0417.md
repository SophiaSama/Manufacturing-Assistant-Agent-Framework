## Problem Description
RB-07 faulted with E-4012 at 07:55 during production start. Fault recurred twice after reset, so escalation per SOP-TEC-201 §5 (Level 2) was triggered.

## Root Cause
Servo amplifier (axis 1) failed — visual inspection found swollen capacitors. No cable chafing found.

## Corrective Action
1. Replaced servo amp with spare SP-RX-04012.
2. Ran 30-minute servo soak test at 30% speed — no fault.
3. Verified TCP calibration unaffected (deviation 0.12 mm).
4. Line restarted 09:15.
