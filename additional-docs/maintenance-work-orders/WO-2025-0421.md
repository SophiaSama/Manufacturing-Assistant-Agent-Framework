## Problem Description
False jam alarm at the Zone 2B transfer point. Photoelectric sensor PS-200-1 blocked by weld spatter accumulation. This is the 4th RC-01 event in 30 days (most common recurring issue, per TEC-328 §6).

## Root Cause
Weld spatter from RB-07 drifting onto the sensor face during robot operations. Sensor mounting angle allows spatter deposit.

## Corrective Action
1. LOTO applied; cleared spatter from PS-200-1 and PR-100-1.
2. Verified 3 successful transfers at jog speed, then full speed (per SOP-TEC-228 §3.3).
3. Adjusted sensor shield deflector (temporary mitigation).

## Permanent Action Recommendation
- Permanent PCA: install air-knife deflector over PS-200-1. Tracked in CMMS as enhancement ENH-2025-118; scheduled for next plant shutdown.
- Note: 4 RC-01 events in 30 days is below the 8D trigger (3 identical NCs/30 days does not apply to housekeeping-type events, but FAP-401 §2 item 4 may apply if >2 h line stop occurs).
